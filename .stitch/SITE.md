# Tender AI - Stitch 實驗場站點與重構計畫 (SITE.md)

本文件定義了 **Tender AI** 重塑計畫中的**全站頁面藍圖與使用者流程**。我們將本專案的全部介面劃分為 6 個核心實驗頁面，並提供全新的互動與設計構想，旨在透過 Stitch 實驗激發更好的設計靈感。

---

## 1. 重構後的使用者流程 (Re-imagined User Flow)

我們為 David (主要挑案決策者) 設計了更高效、沉浸的「黃金挑案路徑」：

```
+------------------+      +------------------+      +------------------+
|                  |      |                  |      |                  |
|  1. 首頁指揮中心  +----->+  2. 標案超級清單  +----->+  3. 詳情規格常駐  |
|  (Dashboard Hub) |      |   (Super List)   |      |  (Spec Detail)   |
+--------+---------+      +--------+---------+      +--------+---------+
         |                         |                         |
         v                         v                         v
+--------+---------+      +--------+---------+      +--------+---------+
|                  |      |                  |      |                  |
|  4. 行動招標看板  |      |  5. 快速速配滑卡  |      |  6. 規則與大腦  |
|  (Kanban Board)  |      |   (Swipe Deck)   |      |  (Brain Admin)   |
+------------------+      +------------------+      +------------------+
         ^                         ^                         ^
         |                         |                         |
         +-------------------------+-------------------------+
                                   |
                                   v
                    [ 全站隨身 AI 標案助手 (FAB) ]
```

1.  **首頁指揮中心**：David 登入後第一眼看到「今日大腦重點推薦」、「Layer B 團隊具名貢獻榮譽板」與「當前學習大腦健康度」。
2.  **標案超級清單**：David 點擊進入清單。清單支援一鍵切換「卡片 Bento 視圖」與「高密度表格視圖」。列表直接顯示可行性分數儀表，David 可以在這裡快速按 ✓承接 / ✗略過，或隨時框選關鍵字。
3.  **詳情規格常駐**：若需要看詳細內容，David 可點擊進入獨立詳情頁。頁面將繁瑣的招標文件轉化為「常態性規格表」，包含履約、資格、押標金、附件等分區，右側常駐「AI 相似案推薦與 RAG 文件頁碼引用」。
4.  **行動招標看板**：已被承接的標案自動轉為 Kanban 卡片。在這裡，David 可以隨時點開卡片加入具名筆記（行為層 Layer B），或直接拖曳轉傳指派給白名單內的同事（例如 Aaron）。
5.  **快速速配滑卡**：在零碎時間，David 可以使用 Swipe 介面。像交友軟體般，左滑淘汰、右滑精選，快速完成第一輪標案清洗。
6.  **規則與大腦**：Admin (或 David 本人) 在此微調關鍵字與預算篩選閾值，並查看 AI 自演化狀態 (Sample 數是否滿 50 觸發演化)。

## 2. 實驗頁面清單與 Stitch 狀態

以下是我們在 Stitch 中進行介面靈感實驗的頁面清單。您可以使用 `stitch-loop` 技能配合接力棒 `.stitch/next-prompt.md` 逐一生成。

| 頁面代號 (`page`) | 頁面名稱 | 重新設計靈感亮點 | 狀態 |
| :--- | :--- | :--- | :--- |
| `dashboard` | 首頁指揮中心 | Bento 區塊佈局、KPI 指標儀表、大腦學習健康度視覺化。 | `[ ] 待生成` |
| `tenders` | 標案超級清單 | 帶有滑桿與複選的 Filter Bar，可行性分數 Gauge，✓/✗ 行動按鈕。 | `[ ] 待生成` |
| `tender-detail` | 詳情規格常駐 | 資訊分欄 (事實格、資格、附件)，右側 RAG 對話與相似案推薦卡片。 | `[ ] 待生成` |
| `kanban` | 行動招標看板 | 可拖拽欄位，具名註記計數徽章，轉傳選單。 | `[ ] 待生成` |
| `swipe` | 快速速配滑卡 | 卡片疊加視效，卡片上有核心履約資訊與「為何推薦」歸因徽章。 | `[ ] 待生成` |
| `brain-settings` | 規則與大腦設定 | 關鍵字加權/排除編輯器，大腦切換器 (Ollama/CLI/BYOK)，自演化狀態。| `[ ] 待生成` |
