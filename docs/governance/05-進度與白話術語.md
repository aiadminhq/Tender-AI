# 05 ｜ 進度與白話術語（給非技術夥伴）

> 先讀 `00-總覽與心智模型.md`。本檔讓任何人都能用白話聽懂「現在做到哪、什麼意思」。

---

## 1. 白話術語表

| 你會聽到的詞         | 白話意思                                                                                               |
| -------------------- | ------------------------------------------------------------------------------------------------------ |
| Layer A              | 「抓回來的標案資料」                                                                                   |
| Layer B              | 「同事們的收藏/評分/想法——白名單公司帳號內與 AI 共享、依登入名字具名、互相學習（經同意；對外不外流）」 |
| Layer C              | 「系統學出來的判斷（會越來越準）」                                                                     |
| 向量 / Embedding     | 「把文字變成數字，讓電腦能比『意思像不像』」                                                           |
| RAG                  | 「AI 回答前先去翻資料庫找證據，再根據證據回答」                                                        |
| pgvector / Ollama    | 「存向量的資料庫」／「在地端跑 AI 模型的引擎」                                                         |
| backfill             | 「把歷史資料一次補進系統」                                                                             |
| 學習迴圈 / Evolution | 「你越用，它越懂你要什麼」                                                                             |
| 可行性分數           | 「這個案子值不值得投，0–100 的估算」                                                                   |
| 推薦理由             | 「為什麼推薦／不推薦這案，給你看得懂的原因」                                                           |
| fire-and-forget      | 「先讓畫面動起來，背景再默默回報後端，後端慢或失敗也不卡你」                                           |
| mock 資料            | 「暫時用的假資料，方便先看畫面，之後換真的」                                                           |
| 分支 / branch        | 「同一份程式的一條獨立工作線，互不干擾」                                                               |

## 2. 統一的進度標記（只用這六個，不要自創）

| 標記 | 狀態   | 白話                                        |
| ---- | ------ | ------------------------------------------- |
| 🔲   | 規劃中 | 還在想，還沒動工                            |
| 🟡   | 開發中 | 正在寫                                      |
| 🟢   | 已串接 | 程式通了，能跑（但可能還在用假資料/待驗收） |
| ✅   | 已驗收 | 真資料跑過、確認 OK                         |
| ⏸    | 暫緩   | 先放著                                      |
| 🐞   | 卡住   | 有問題，需要決策或協助                      |

## 4. 每次回報的固定格式（白話三段式）

> 1. **做了什麼**（白話一句）
> 2. **怎麼驗的 / 有沒有真的跑過**（測試？真資料？還是只到畫面？）
> 3. **接下來 / 卡在哪**（要不要決策）
