# Phase 2 真鑑權實作計畫（HMAC 簽章 token）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 登入簽發可驗證（HMAC 簽章、防竄改、帶到期）的 stateless token，後端從 token 推導身分／角色，取代「信任前端帶入的 `user_id` 與 `X-User-Role`」，使多人共享內網時具名 Layer B 貢獻與 admin 權限不可偽造；完成後翻部署設定讓 David 從 `http://192.168.26.70:8771/` 登入操作。

**Architecture:** 新檔 `app/core/auth.py` 放純 stdlib HMAC token（issue/decode）＋兩個 FastAPI dependency（`get_current_user`／`require_admin_user`）。token 只放 `uid`，每次請求從 DB 撈最新 `role`／`whitelist_active`（近即時撤銷，免 session 表）。`X-API-Key` 維持外層粗閘，token 是內層具名身分層。前端把 token 存 `localStorage`、`authHeaders` 加 `Bearer`、開站打 `GET /me` 驗證、401 自動登出、登入閘擋匿名。

**Tech Stack:** Python 3 / FastAPI / SQLAlchemy async / pydantic-settings（後端，零新相依）；React 18 / TypeScript / Vite / vitest（前端）。

## Global Constraints

> 以下為 spec 與專案規範的全域約束,每一個 task 的要求都隱含包含本節。值一律照抄,不得改寫。

- **零新相依**：token 只用 stdlib `hmac`/`hashlib`/`base64`/`json`；不引入 PyJWT。與 `app/core/security.py` 既有 pbkdf2 全 stdlib 決定同調。
- **`AUTH_SECRET`**：放 `.env`（gitignored），**無安全預設值**（預設空字串）；缺值時 `issue_token`／`decode_token` 直接 `raise`。`.env.example` 附產生指令 `python -c "import secrets; print(secrets.token_urlsafe(48))"`。測試由 `conftest` 注入測試值。secret 絕不印出、不入 log、不進版控。
- **TTL**：`AUTH_TOKEN_TTL_HOURS` 預設 `168`（7 天）。
- **token 格式**：`base64url(payload).base64url(hmac_sha256(payload, AUTH_SECRET))`，payload `{"uid": <int>, "exp": <unix>, "iat": <unix>}`。token **只放 uid**，role／whitelist_active 每次請求從 DB 撈。
- **驗簽**：一律 `hmac.compare_digest`（防 timing attack）。
- **狀態碼**：無／非 `Bearer `／壞／過期 token、查無 uid → **401**（`HTTPException`）；`whitelist_active is False`、非 admin → **403**（沿用既有 `PermissionDenied`，已對應 403）。
- **強制 token 邊界（surgical）**：`/me/*`、`/admin/*`、行為寫入端點（events / evaluate / tender 狀態 accept·rate·save / saved-searches / manual keywords）。**維持只靠 X-API-Key**：唯讀 Layer A（標案列表、tender 詳情含 user_state、keyword-candidates、reasoning 解釋、evolution、decision search）——避免打斷 MCP／自動化既有用 X-API-Key 讀公開資料的路徑。
- **不做（YAGNI）**：refresh token、伺服器端 session／撤銷清單、多裝置管理、SSO/OAuth、密碼複雜度政策強化（沿用 `MIN_PASSWORD_LENGTH`）。
- **同意模型（opt-out，2026-06-25 owner 決定）**：`seed_members` 新建帳號 `consent_shared=True`、既有帳號**不觸碰**；設定頁同意開關改 opt-out 呈現；consent-aware 學習閘（`whitelist_active && consent_shared`）、append-only 審計、可回退安全網**不動**。

- [ ] **Step 3：實作 `app/core/auth.py`（token 部分）**

```python
"""Phase 2 鑑權：stdlib HMAC 簽章 stateless token。

格式：base64url(payload).base64url(hmac_sha256(payload, AUTH_SECRET))
payload：{"uid": <int>, "exp": <unix>, "iat": <unix>}
token 只放 uid；role / whitelist_active 每次請求從 DB 即時撈（近即時撤銷，免 session 表）。
零新相依（hmac/hashlib/base64/json）。日後升 JWT/SSO 只改本檔。
"""

from __future__ import annotations

import base64
import hashlib
import hmac
import json
import time

from app.core.config import settings


def _b64url_encode(raw: bytes) -> str:
    return base64.urlsafe_b64encode(raw).rstrip(b"=").decode("ascii")


def _b64url_decode(s: str) -> bytes:
    pad = "=" * (-len(s) % 4)
    return base64.urlsafe_b64decode(s + pad)


def _secret() -> bytes:
    secret = settings.auth_secret
    if not secret:
        raise RuntimeError("AUTH_SECRET 未設定，拒絕簽發／驗證 token（避免空祕密誤上線）")
    return secret.encode("utf-8")


def _sign(payload_b64: str) -> str:
    sig = hmac.new(_secret(), payload_b64.encode("ascii"), hashlib.sha256).digest()
    return _b64url_encode(sig)


def issue_token(user) -> str:
    now = int(time.time())
    exp = now + settings.auth_token_ttl_hours * 3600
    payload = {"uid": int(user.id), "iat": now, "exp": exp}
    payload_b64 = _b64url_encode(
        json.dumps(payload, separators=(",", ":")).encode("utf-8")
    )
    return f"{payload_b64}.{_sign(payload_b64)}"


def decode_token(token: str) -> dict | None:
    if not token or not isinstance(token, str) or "." not in token:
        # 仍需確認 secret 存在（缺值要 raise，符合 spec §2.2）
        _secret()
        return None
    payload_b64, _, sig_b64 = token.partition(".")
    expected = _sign(payload_b64)
    if not hmac.compare_digest(sig_b64, expected):
        return None
    try:
        payload = json.loads(_b64url_decode(payload_b64))
    except (ValueError, json.JSONDecodeError):
        return None
    if not isinstance(payload, dict) or "exp" not in payload or "uid" not in payload:
        return None
    try:
        if int(payload["exp"]) < int(time.time()):
            return None
    except (TypeError, ValueError):
        return None
    return payload
```

> 注意：`decode_token("anything.anything")` 在缺 secret 時要 raise——上面 `_sign` 會先呼叫 `_secret()` 而 raise,符合 `test_missing_secret_raises`。`decode_token("")`／`"not-a-token"` 在「有 secret」時走早退 `_secret()`（不 raise）後回 `None`,符合 `test_garbage_token_rejected`。

```python
from fastapi import Depends, Header, HTTPException, status
from sqlalchemy.ext.asyncio import AsyncSession

from app.core.errors import PermissionDenied  # 路徑以 Task 4 Step 1 確認為準
from app.db.session import get_session         # 同上
from app.models.behavior import User


async def get_current_user(
    authorization: str | None = Header(default=None),
    session: AsyncSession = Depends(get_session),
) -> User:
    if not authorization or not authorization.startswith("Bearer "):
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="缺少 Bearer token")
    token = authorization[len("Bearer "):].strip()
    payload = decode_token(token)
    if payload is None:
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="token 無效或已過期")
    user = await session.get(User, int(payload["uid"]))
    if user is None:
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="查無此使用者")
    if not user.whitelist_active:
        raise PermissionDenied("帳號未在白名單或已停用，請洽管理員")
    return user


async def require_admin_user(user: User = Depends(get_current_user)) -> User:
    if user.role != "admin":
        raise PermissionDenied("需要管理員權限")
    return user
```
