# Tender AI 專案現況評估（全棧打通盤點）

針對五大面向做一次「現在到底做到哪」的盤點：PCC 資料抓取與入庫、前台頁面/功能、assistant-ui 整合、後端資料庫與知識庫學習，最後判定全棧是否打通。結論先講：**核心鏈路已打通、可離線重現（~180 支測試、21 檔），整體完成度約 90–93%**。本次更新反映近期落地的大進度——**白名單登入（@hqdesign.tw）＋ user_id 具名已實作**（前端 `setCurrentUserId/withUser` 注入、後端 `Event.user_id` 為 NOT NULL FK），**Layer B Phase 1 全套到位**（白名單 + 兩段式同意 + 個人偏好輪廓 + 雙軌學習），**enrich 履約/資格/押標金/附件欄位與詳情 API 讀取端已落地**，**assistant Phase 1 引導 onboarding 也已完成**。剩餘卡點集中在：PCC 詳情頁「常駐型 CAPTCHA」、assistant Phase 2–4（全螢幕/情境/留存）、`/search/semantic` 與 `/evolution/*` 的前端入口，以及 category 空值率。

本文件為**唯讀評估**，未改動任何原始碼；確認方向後再進實作。

</RichText>

<Callout id="overall" tone="success">

**全棧可端到端跑通**：PCC 抓取 → 解析 → revision-first 入庫 → 向量化 → 查詢/相似/理由 → 前端已接 25/28 路由（含登入/帳號/同意/白名單/語意搜尋/進化）。資料能從原始 HTML 重建（Layer A），知識層（Layer C）可重算。**Layer B 具名共享已從佔位轉為真實**（白名單登入 + user_id FK 落地）。剩餘缺口為**抓取自動化**（CAPTCHA）與**前端 UI 入口**（semantic/evolution）等，列於下方各節與 Open Questions。

### 4. 後端資料庫與知識庫學習

PostgreSQL + pgvector，25 張表、13 個 Alembic migration。revision-first 永不 UPDATE。P1–P4 完成、約 180 支測試（21 檔）。**Layer B Phase 1 已落地**：`User` 表（password_hash pbkdf2_sha256、whitelist_active、consent_shared、consent_at）、白名單限定 `@hqdesign.tw`（`account.set_whitelist`）、兩段式同意、個人偏好輪廓（`PreferenceProfile`）、`UserKeywordWeight`（複合 PK user_id+term）。**雙軌學習**：團隊線受 `whitelist_active and consent_shared` 雙閘控、個人線免同意（`learn_keywords._learn_personal_line`）。P4 關鍵字權重學習＝category Tier-1 對映 + TF 詞頻比較 + 版本快照。向量 bge-m3 1024 維、HNSW cosine。
