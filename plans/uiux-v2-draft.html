這份草稿把另一 agent 的 uiux-v2-plan（N1–N4）、現有前端的設計 token，與儀表板參考視覺整合成一套「整體介面＋使用流程」的大概版。暗色為主、可切亮色；字體維持 Noto Sans TC／Inter／JetBrains Mono 三族，只調整字級與字重。

範圍 5 個主畫面 ＋ 三層下鑽 ＋ 流程 字族 不變，字級字重重訂 技術 React · Tailwind v4 · 自寫 primitive（無 Radix） 圖表 自寫 inline SVG
FOUNDATION

五條設計原則

v2 不是換皮，是把「資訊密度」與「決策路徑」重排。所有畫面都服從這五條。

01

決策優先，不是資料優先

每個畫面先回答「我現在該看哪幾案、為什麼」，圖表與細節是支撐，不是主角。今日焦點＝主欄，概覽輔助＝側欄。

02

一眼摘要，逐層深入

L1 卡片掃描 → L2 就地展開比對 → L3 彈窗看全貌。深入是「想知道更多」時才發生，不強迫一次給滿。

03

克制的色彩語意

白 pill＝主行動；signal 藍只給連結/聚焦；綠/琥珀/紅只表潛力分級與狀態。色彩永遠搭文字或圖示，不單靠顏色傳意。

04

數字是一等公民

預算、天數、分數、佔比一律 JetBrains Mono ＋ tabular-nums，欄位對齊、不跳動。大數字用 Display 級當錨點。

05

Bento 可組裝

面板＝可放大（L3 lightbox）、未來可依個人習慣用 grid 重排的積木。統一 16px 圓角、些微陰影、零濃重投影。

TOKENS

直接沿用 src/index.css 既有 token（暗色為主、亮色覆寫）。v2 不新增主色，只是更有紀律地使用。點右上角可切換亮/暗即時預覽。

TYPOGRAPHY

字體系統（v2 調整）

字族維持三套：繁中 Noto Sans TC、英文 Inter、數字/程式碼 JetBrains Mono。v2 把 body 從 15px 收到 13.5px 提高密度、拉開階層對比，並把大數字升為 Display 級當視覺錨點。字重收斂為 400/500/600/700 四級。

INTERACTION MODEL

三層下鑽模型

統一全站的「看更多」邏輯：掃描 → 比對 → 全貌。N1 已確認採兩段式但讓「快速預覽」更顯眼。

L1 · 卡片掃描

一行一案

標題＋可行性分數＋截止倒數。密度高，整列可點。目的：快速略讀今天有什麼。

L2 · 就地展開

同卡手風琴

點列在原位展開事實格＋標籤＋兩顆入口。不跳頁、不蓋畫面，方便上下多列並排比對。

L3 · 彈窗全貌

置中 lightbox

點「快速預覽」開完整彈窗：可行性 meter、下一步、關鍵字命中、評價、轉傳、筆記。Esc／點背景關閉。

L1 列  →  L2 展開  →  L3 彈窗  ·  「查看完整詳情」→ 獨立頁 /tenders/:id
